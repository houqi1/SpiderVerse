# Line Art 连接与性能说明

## 当前连接规则

1. 网格预处理按位置量化焊接顶点，格子大小为 max(网格包围盒对角线 × 1e-6, 1e-7)。这不是距离半径搜索，跨格的近邻点仍可能不合并。
2. 候选边按优先级归入轮廓、折痕、材质边等一种类型。折痕角 120 表示相邻法线夹角大于 60°。
3. 先裁视锥、算遮挡，再连接可见片段。原规则仅连接同一物体、同一类型、共享端点标识的边，而且端点必须恰好关联两条边。三叉、四叉处停止；并不检查是否共线。
4. 相交线使用物体对及世界坐标量化标识，普通边使用焊接顶点编号，二者不会自动混接。遮挡/视锥裁切产生独立端点，不跨遮挡连接。
5. 连接完成后，对整笔应用 Length Trim、Length Randomness、End Taper。默认随机度 0.4 会使线长处于原长度的 60–140%；分笔会让相邻线分别缩短或延长，看起来断开或重叠。

## 新暴露的参数

在使用中的 Object Line Art Renderer Feature → Settings → Stroke connections：

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| Connect Different Edge Types | 关闭 | 允许同物体、共享网格端点的不同线型接成一笔 |
| Connect Junctions | 关闭 | 分叉处允许互为最直延续的两条边连接 |
| Junction Max Angle | 20° | 分叉处允许的屏幕空间转角，0° 表示只接直线；不限制原有两边端点 |

默认保持旧行为。建议排查时先将 Length Trim、Length Randomness、End Taper 临时设为 0，区分几何断开和笔触缩短；再启用两个连接开关，从 10–20° 调整分叉角。连接变化会改变整笔长度、随机种子、贴图分布，这是改变笔划分组的自然结果。

这些参数不跨物体、不跨真实空间缝隙、不补遮挡缺口。屏幕上共线但端点不共享的线仍不会相连。屏幕距离吸附需要同时限定世界距离/深度和可见性，否则容易把前后景误接，因此本次没有加入通用吸附。

## 纹理不透明度与旋转

Random Offset 位于 Stroke appearance (pixels)，X/Y 分别是每笔屏幕水平/垂直随机偏移的最大像素幅度，例如 (2, 1) 表示 X 在 ±2 像素、Y 在 ±1 像素内。默认 (0, 0) 关闭。连接成一笔的所有顶点使用同一偏移，叠加在原 Offset 上；不按细分小段独立移动，因此不会撕开一笔。随机值来自既有笔划种子，不随时间变化；连接或遮挡变化导致笔划身份改变时，随机偏移也可能改变。只更新材质，不重建几何。偏移在遮挡计算之后应用，较大幅度可能使线条离开原几何轮廓。

Texture Rotation（−180°～180°）绕笔触 UV 中心旋转采样，再沿纹理 U 方向应用 Texture Repeats。0° 保持原采样方向。旋转发生在笔触 UV 空间，不是屏幕像素空间。

Texture Tiling 为二维 UV 缩放，默认 (1, 1)；Texture Offset 为二维 UV 偏移，默认 (0, 0)，1 表示一个完整纹理周期。采样顺序为绕中心旋转 → Tiling（X 同时乘原有 Texture Repeats）→ Offset。例如 Tiling (2, 3)、Repeats 1 表示 U/V 分别重复 2/3 次；负 Tiling 可镜像纹理。它们只移动/缩放不透明度 mask，不移动描边几何，也不触发几何重建。

纹理仅控制不透明度，不再乘到描边 RGB：默认使用纹理亮度 × Alpha，白色显示、黑色透明；Dark On White Mask 开启后使用（1 − 亮度）× Alpha，黑色显示、白色透明。Texture Strength 为 0 时不受纹理影响，为 1 时完整应用 mask。最终颜色始终来自 Color，最终不透明度还会乘 Color Alpha 和线条边缘覆盖率。这些参数只更新材质，不重建几何。

## 已实施的等价优化

- 三角形裁切增加六平面的快速接受/拒绝。完全在视锥内部时免去逐平面临时列表；跨平面的三角形仍走原裁切流程。
- 生成索引时直接写入六个索引，移除每个线段的临时 int 数组。

## 后续不降低表现的优化优先级

以下是代码审查得出的候选方案，尚未做场景 Profiler 测量，不承诺具体提速比例。

1. **主线程快照与蒙皮复用。** 当前每台相机每次 Capture 都会读取顶点、BakeMesh、转换世界坐标、计算哈希，即便最后发现无需重建。可让同一帧各相机共享不可变几何快照，再分别投影；静态网格缓存顶点，变换/网格/材质变化时失效。运行时修改 Mesh 必须有显式失效机制，不能只检查引用和 Transform。
2. **拆分缓存阶段。** 现有拓扑缓存、相交线缓存已实现，但仅改长度参数仍重算投影和遮挡。可缓存可见 spans / chains，把线型、遮挡、连接、笔触几何分别失效；只改长度时重建最终笔触。注意相机、动画和遮挡物变化必须使前级缓存失效。
3. **减少遮挡候选。** 当前固定 48×48 屏幕网格按线段包围矩形访问桶，长斜线会访问很多无关桶。可采用保守的线段穿格遍历或层级屏幕包围盒，继续使用原 Hidden 精确测试。必须覆盖边界和角点相交，不能跳过可能遮挡的三角形。
4. **减少分配。** 用结构化数值键代替字符串端点键；复用工作线程私有列表/缓冲区；避免 PlaneCut 每对三角形分配数组和列表。字符串键同时参与随机种子，替换时要保持原种子规则，否则笔触随机外观会变。
5. **相交加速结构复用。** 动态对象可对已有 BVH 做 refit，静态对象缓存世界三角形；相机运动不应使相交缓存失效（当前已有此优化）。必须正确处理拓扑和物体集合变化。

不把降低 Update Rate、关闭 Intersections/Occlusion、增加笔触采样间距列为“无损”方案：它们分别影响运动响应、线条内容、遮挡或噪声/粗细表现。

## 验证

独立 Unity 6000.0.48f1 批处理工程检查连接与裁切逻辑：默认 T 分叉断开、开启后直线续接、跨类型开关、角度接受/拒绝、十字交叉配对、开放链不误判闭环、视锥内/外三角形。回归入口为 LineArtConnectionChecks.Run，仅允许在隔离批处理工程运行。未进行当前场景的视觉对比和帧时间基准。
